# تصمیم‌های بستهٔ سایت — ۲۰۲۶-۱۱-۰۵

این بسته فقط منابع، آزمون‌ها و مستندات ردیابی‌شدهٔ سایت را تغییر می‌دهد؛ اپ‌ها، مولد، مهر، پراکسی، پایگاه‌داده و استقرار عمداً خارج از محدوده ماندند.

- صفحهٔ نخست چهار هدف را جدا می‌کند: سرمایهٔ کوچک، هدیه، یادگیری و مراقبت. متن ارزش بیت‌کوین را انکار نمی‌کند و وعدهٔ سود یا امنیت مطلق نمی‌دهد.
- بخش «این پاکت چه چیزی دارد» پیش از توضیح بیت‌کوین آمده و توضیح ساتوشی به بخش `#satoshi` در همان راهنما منتقل شده است. `/satoshi` برای لینک‌های قدیمی به همان بخش ۳۰۱ می‌دهد.
- عنوان‌های عمومی هزینه به «هزینه‌ها» کوتاه شدند. محاسبه و قرارداد ۰٫۱۸ دلار چاپ و مهر و حداقل اصل ۵۰۱ ساتوشی دست‌نخورده ماند و متن مستند اصلاح شد.
- `robots.txt` و `sitemap.xml` فقط صفحه‌های عمومی آموزشی را معرفی می‌کنند. هزینه‌ها، تماس، استعلام، API و داده‌های وابسته به مشتری عمداً در SEO عمومی نیامده‌اند.
- امکان GitHub Pages فقط در سند امکان‌سنجی ثبت شد؛ قابلیت زنده، DNS و انتشار انجام نشد.

## آزمون و وضعیت اجرا

- `python3 -m unittest discover -s bitcoin4funsite/tests -p 'test_pricing.py' -v`: موفق، ۲۸ آزمون.
- `python3 -m unittest discover -s bitcoin4funsite/tests -p 'test_address_contract.py' -v`: موفق، ۲ آزمون.
- render آفلاین همهٔ ۱۳ قالب با Jinja: موفق.
- `node --check` برای `calculator.js`، `site.js` و `security.js`: موفق.
- `python3 bitcoin4funsite/tests/check_publication_guard.py`: موفق؛ کنترل‌های منفی و مثبت.
- آزمون قراردادی خانه، راهنمای تازه و لینک هزینه: موفق؛ آزمون مستقل همان لینک نیز موفق.
- مجموعهٔ کامل `python3 -m unittest discover -s bitcoin4funsite/tests -v` اجرا شد اما محیط این نشست `flask` و `bech32` و چند وابستگی قفل‌شده را ندارد؛ نتیجهٔ خام ۲۷۷ آزمون، ۱ شکست متنیِ اصلاح‌شده و ۱۰۷ خطای import بود. آزمون‌ها به سرویس بیرونی وصل نشدند. Docker daemon نیز برای بازسازی محیط در دسترس نبود.

## نتیجهٔ بررسی مستقل میزبان

عامل‌های خط فرمان در محیط جداشده به محیط وابستگی میزبان دسترسی نداشتند؛ گزارش نبود وابستگی نقص محصول نبود. پس از اصلاح یک آزمون قدیمی که هنوز مسیر عمومی خزنده را نامعتبر می‌دانست، مجموعهٔ کامل میزبان موفق شد.

```text
.venv/bin/python -m unittest discover -s bitcoin4funsite/tests -v
Ran 321 tests in 53.942s
OK (skipped=5)
```

نمایش واقعی راهنما و بخش مهر در مرورگر بررسی شد؛ متن راست‌به‌چپ خواناست و مهر کامل و بدون بریدگی نمایش داده می‌شود. نشان فعال اشتباه شرایط در خانه اصلاح شد. بخش مهر از بردار پاک‌سازی‌شده استفاده می‌کند؛ فایل اصلی و عکس منتشر نمی‌شوند و طرح از مجوز عمومی مخزن مستثناست. این مدرک آزمون دستگاه اندروید یا اصالت پاکت نیست.

این سند به‌تنهایی استقرار یا انتشار عمومی را ثابت نمی‌کند؛ ثبت شناسهٔ بازبینی، نتیجهٔ بررسی میزبان و بررسی نسخهٔ زنده در گزارش ادغام جدا خواهد آمد.
