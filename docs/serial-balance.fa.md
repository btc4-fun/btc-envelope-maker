# موجودی در صفحهٔ سریال

## رفتار و حریم خصوصی

«نمایش آدرس» و کد تصویری فقط از نگاشت عمومی سایت استفاده می‌کنند. «نمایش موجودی» انتخابی جداست؛ بدون انتخاب آن هیچ درخواست موجودی به بیرون نمی‌رود. فرم بدون جاوااسکریپت هم کار می‌کند. صفحهٔ دارای نتیجه، آن را بدون استعلام دوباره بازسازی می‌کند.

پس از اعتبارسنجی و پذیرش سهمیه، یک بار نگاشت عمومی خوانده می‌شود. فقط آدرس معتبر همان نگاشت به منبع ثابت می‌رود؛ کاربر نمی‌تواند آدرس یا منبع دیگری تعیین کند. منبع، آدرس عمومی و اتصال سرور را می‌بیند؛ سریال، نشانی اینترنتی کاربر، کوکی یا هدرهای او ارسال نمی‌شوند. کلمات بازیابی هرگز لازم نیستند.

```text
https://blockstream.info/api/address/ADDRESS
```

انتقال امن موجود با بررسی گواهی، مهلت چهارثانیه‌ای، سقف پاسخ دویست‌وشصت‌ودو هزار و صد‌وچهل‌وچهار بایت و رد تغییر مسیر بازاستفاده می‌شود. کش موجودی، تاریخچه، تازه‌سازی خودکار و تکرار خودکار نداریم.

## قرارداد درخواست

تنها گزینهٔ موجودی، مقدار زیر است. نبود گزینه همان پاسخ سه‌فیلدی قبلی را حفظ می‌کند. گزینهٔ تکراری، مقدار دیگر و پارامتر ناشناخته پیش از سهمیه و خواندن داده رد می‌شوند. فرم فقط یک سریال می‌پذیرد. کد تصویری و استعلام معکوس گزینهٔ موجودی ندارند.

```text
GET /api/wallets/SERIAL?balance=1
GET /s/SERIAL?balance=1
GET /SERIAL?balance=1
GET /lookup?serial=SERIAL&balance=1
```

پاسخ موفق، سه فیلد نگاشت قبلی و شیء موجودی را دارد. اعداد این نمونه ساختگی‌اند و شاهد وضعیت شبکه یا موجودی واقعی نیستند:

```json
{
  "serial": "TEST-DO-NOT-FUND-0587k45300",
  "address": "bc1qcr8te4kr609gcawutmrza0j4xv80jy8z306fyu",
  "explorer_url": "https://mempool.space/address/bc1qcr8te4kr609gcawutmrza0j4xv80jy8z306fyu",
  "balance": {
    "address": "bc1qcr8te4kr609gcawutmrza0j4xv80jy8z306fyu",
    "confirmed_sats": 500,
    "pending_delta_sats": -50,
    "source": "https://blockstream.info/api",
    "fetched_at": "1970-01-01T00:16:40+00:00"
  }
}
```

موجودی تأییدشده و تغییر خالص در انتظار جدا هستند؛ تغییر می‌تواند منفی باشد. نمایش بیت‌کوین با هشت رقم اعشار و محاسبهٔ صحیح دقیق است. زمان، آغاز دریافت در سرور به وقت جهانی است؛ زمان منبع یا تضمین هم‌زمانی شبکه نیست. این اعداد اثبات اصالت، مالکیت یا قابلیت خرج نیستند.

خطای منبع، پاسخ ناموجود همراه همان نگاشت عمومی و بدون عدد موجودی است:

```text
HTTP 503
balance_error: unavailable
```

خطای سهمیه یا پایگاه داده هیچ نگاشت تازه‌ای تضمین نمی‌کند. در مرورگر، نگاشت قبلاً نمایش‌داده‌شده برای همان سریال هنگام خطای دریافت حفظ می‌شود. تغییر سریال، درخواست تازه یا خروج، پاسخ قبلی را بی‌اعتبار می‌کند؛ لغو مرورگر نمی‌تواند درخواست بیرونیِ از پیش پذیرفته‌شده در سرور را برگرداند.

```text
400: invalid_lookup_request / invalid_serial
404: not_found
429: rate_limited + retry_after + Retry-After
503: unavailable
```

هر انتخاب موجودی یک پذیرش معمول از همان سهمیهٔ پنج استعلام در شصت ثانیه مصرف می‌کند؛ حتی برای همان سریال و حتی اگر منبع خطا دهد. سهمیه با مسیرهای سریال و معکوس مشترک است. سهمیهٔ تگ مستقل است. سیاست پیشوند نشانی و پراکسی مورد اعتماد بدون تغییر می‌ماند. کد تصویریِ همراه پذیرش معتبر سهمیهٔ تازه مصرف نمی‌کند؛ این استثنا شامل موجودی نیست.

## راه‌اندازی و مرز انتشار

تنظیم، کلید، ستون، مهاجرت یا مجوز جدید پایگاه داده لازم نیست. فقط ماژول‌ها و دارایی‌های سایت در تصویر ثابت منتشر شوند. تنظیمات امنیتی موجود، وضعیت سهمیه، گزارش تگ، داده، اسرار و پراکسی مشترک حفظ شوند. فعال‌سازی موجودی سریال به فعال‌سازی تگ وابسته نیست. بستهٔ آفلاین هیچ اپی با این تغییر بازسازی نشده است.

پیش از استقرار، تصویر فعال و تنظیم بازگشت تازه خوانده و نسخهٔ پشتیبان تنظیم تهیه شود. آزمون مصنوعیِ جدا و بدون شبکه و تطبیق همهٔ فایل‌های کانتینر با کامیت لازم است. ساخت یا آزمون محلی به‌تنهایی شاهد استقرار نیست.

## آزمون

از ریشهٔ مخزن سایت و محیط جدا از تنظیم تولید:

```sh
env -u BTC_TEST_OWNER_PASSWORD_FILE -u NFC_TEST_POSTGRES python3 -m unittest discover -s bitcoin4funsite/tests -v
node --check bitcoin4funsite/static/site.js
python3 bitcoin4funsite/tests/check_publication_guard.py
git diff --check
```

آزمون‌ها از نگاشت و پاسخ مصنوعی استفاده می‌کنند؛ شمارش یک دریافت، عدم دریافت تاریخچه، رد گزینه، سهمیهٔ مشترک، صفر واقعی، تغییر منفی، خطا و پاسخ دیرهنگام را پوشش می‌دهند. آزمون پایگاه دادهٔ واقعی فقط با تنظیم صریح محیط موقت اجرا می‌شود. هیچ موجودی واقعی یا رکورد خصوصی برای این پیاده‌سازی خوانده نشده است؛ موفقیت منبع زنده و تطبیق نسخهٔ مستقر باید جداگانه گزارش شوند.
