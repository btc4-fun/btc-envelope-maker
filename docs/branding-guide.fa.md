# راهنمای کوتاه برند و تصمیم‌های باز

این سند فقط وضعیت تأییدشدهٔ برند سایت را ثبت می‌کند. تا زمان بسته‌شدن تصمیم‌های باز، از آن برای ساخت لوگو، favicon یا تغییر هویت بصری استفاده نکنید.

## وضعیت فعلی

- نام نمایشی فارسی سایت در هدر: «بیت‌کوین برای سرگرمی».
- شناسهٔ لاتین فعلی: `btc4fun` و دامنهٔ اصلی عمومی: `btc4.fun`.
- هدر فعلی یک نشان تایپیِ `₿` با CSS دارد؛ این نشان لوگوی رسمیِ تأییدشده محسوب نمی‌شود.
- `bitcoin4funsite/static/seal.svg` مهر تزئینی پاکت است، نه لوگو. طبق `bitcoin4funsite/static/SEAL-LICENSE.md` نباید به‌عنوان لوگو، favicon یا مبنای طراحی برند استفاده شود.
- رنگ نهایی، فایل لوگوی رسمی و نسبت‌های آن هنوز تأیید نشده‌اند. رنگ‌ها و شکل‌های فعلی CSS فقط بخشی از رابط فعلی‌اند، نه مشخصات هویت بصری نهایی.

## تصمیم‌های باز مالک

1. نام رسمی نوشتاری و شکل دقیق نمایش آن در فارسی و لاتین.
2. فایل و نسخهٔ تأییدشدهٔ لوگو، شامل شکل تک‌رنگ و اندازهٔ کوچک.
3. پالت رنگ رسمی و کنتراست قابل قبول آن.
4. شکل favicon پس از تأیید لوگو: فقط علامت مستقل، حروف، یا نسخهٔ دیگری که مالک مشخص کند.
5. مجوز استفاده و محدودهٔ استفاده از فایل لوگو در سایت و پروژه‌های دیگر.

## قاعدهٔ favicon

تا وقتی لوگو و شکل favicon صریحاً تأیید نشده است، favicon جدید نسازید و `<link rel="icon">` یا HTML عمومی را تغییر ندهید. وجود نداشتن favicon فعلی یک تصمیم قابل‌برگشت و کم‌خطر است؛ استفاده از مهر یا `₿` تایپی به‌عنوان جایگزین، تصمیم طراحیِ تأییدنشده خواهد بود.

پس از تأیید مالک، تغییر جداگانه باید فقط فایل‌های favicon، ارجاع لازم و آزمون‌های وجود فایل/ارجاع را شامل شود و مهر پاکت، لوگوی مولد آفلاین و متن‌های حقوقی را تغییر ندهد.
