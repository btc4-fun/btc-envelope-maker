# Pinned public address validator

`bitcoin4funsite/address_validation.py` is an exact byte copy of
`btc_envelope_maker/address_validation.py` from website repository commit
`e0e925c8d224a7595a15261e50e97b50d300a782`.

SHA-256: `ba2a5a631acbabdc5646df83ee1abf4d6e2f9104ad8b3835419c3e74eddf8eaa`.

The standalone generator retains its own copy. Neither repository imports the
other at runtime or in tests. Changes require explicit review in both owners,
updated provenance and matching public contract fixtures; no implicit syncing.
The Pieter Wuille MIT permission/copyright notice is retained in the source;
project additions remain subject to LICENSE.md and NOTICE.

Both owners retain the same `public_contract.json` test vectors. Serial values
are hand-specified expected encodings of the documented Jalali timestamp format,
not outputs generated by the encoder under test. Address examples are public
BIP173/BIP84 vectors; never fund them. The supported address shape remains
lower-case mainnet P2WPKH, not every Bitcoin address format.
