# مولد خروجی آموزشی گیت‌هاب پیجز

این ابزار از قالب‌های فعلی سایت، یک نسخهٔ آموزشی و ایستا می‌سازد. خروجی فقط برای بازبینی و انتشار جداگانه آماده می‌شود و جای سایت اصلی را نمی‌گیرد.

## محدودهٔ صفحه‌ها

فقط این پنج مسیر به صفحهٔ ایستا تبدیل می‌شوند:

```text
/
/guide
/security
/terms
/download
```

برای مسیرهای وابسته به سرور هیچ صفحهٔ ایستایی ساخته نمی‌شود:

```text
/costs
/contact
/lookup
/api
```

پیوندهای این قابلیت‌ها در خروجی به سایت اصلی می‌روند:

```text
https://btc4.fun
```

نشانی مرجع هر پنج صفحه نیز روی سایت اصلی باقی می‌ماند. فایل جلوگیری از پردازش قالب و پروندهٔ راهنمای خزنده‌ها هم ساخته می‌شوند. مولد در سرآیند هر پنج صفحه دستور زیر را می‌گذارد تا خزنده‌های سازگار صفحه را نمایه نکنند ولی بتوانند پیوندهایش را دنبال کنند:

```html
<meta name="robots" content="noindex,follow">
```

خزش باید مجاز باشد تا خزنده بتواند این دستور را ببیند. مسدود کردن خزش به‌تنهایی جلوی نمایه شدن نشانی را نمی‌گیرد. محتوای پروندهٔ راهنمای خزنده‌ها چنین است:

```text
User-agent: *
Allow: /
```

این دستورها کنترل دسترسی نیستند و رعایت آن‌ها به خزنده بستگی دارد.

## میزبانی فقط در ریشه

خروجی برای سایت سازمانی زیر و فقط در ریشهٔ میزبان طراحی شده است:

```text
https://btc4-fun.github.io/
```

پیوندهای محلی و دارایی‌ها از ریشه آغاز می‌شوند. میزبانی پروژه در زیرمسیر پشتیبانی نمی‌شود؛ تغییر نام پوشهٔ خروجی این محدودیت را برطرف نمی‌کند. برای نمونه، این الگوی نشانی مقصد پشتیبانی‌شده نیست:

```text
https://btc4-fun.github.io/project-name/
```

## دارایی‌های مجاز

مولد فقط دارایی‌های عمومیِ فهرست‌شده در خود برنامه را کپی می‌کند. هیچ پیمایش یا کپی کامل پوشهٔ دارایی‌ها انجام نمی‌شود. این سه فایل در هیچ شرایطی وارد خروجی نمی‌شوند:

```text
privatekey.png
publickey.png
calculator.js
```

تصویرهای آموزشی، قلم‌ها، برگهٔ ظاهر، برنامه‌های لازم برای صفحه‌های آموزشی و پرونده‌های مجوز موردنیاز در فهرست مجاز ثبت شده‌اند.

هر دارایی مجاز باید فایل عادی باشد. پیوند نمادین در خود فایل یا هر پوشهٔ والد، حتی اگر مقصدش داخل پوشهٔ دارایی‌ها باشد، رد می‌شود. تمام فهرست پیش از کپی یا چکیده‌گیری دارایی‌ها و پیش از جایگزینی خروجی بررسی می‌شود. نام مجاز، به‌تنهایی مقصد یک پیوند را امن نمی‌کند. هنگام ساخت، درخت ورودی باید ثابت و زیر کنترل کاربر قابل اعتماد باشد؛ این بررسی در برابر تعویض هم‌زمان فایل‌ها تضمین اتمی نمی‌دهد.

## تولید محلی

از ریشهٔ مخزن، یک مسیر خروجی تازه یا خروجی قبلی همین مولد را بدهید:

```bash
python3 scripts/build_github_pages.py /path/to/github-pages-output
```

مولد یک پوشهٔ غیرخالی و بدون نشان خودش را پاک نمی‌کند. بازسازی خروجی قبلی، فایل‌های مانده از اجراهای قدیمی را حذف می‌کند تا صفحهٔ پویا یا دارایی ممنوعه در خروجی باقی نماند.

این پرونده‌ها در ریشهٔ خروجی ساخته می‌شوند:

```text
.nojekyll
robots.txt
source-manifest.json
```

فهرست منشأ، چکیدهٔ همهٔ قالب‌ها و دارایی‌های ورودی، خود مولد و همهٔ فایل‌های دیگر خروجی را ثبت می‌کند. زمان ساخت در آن نوشته نمی‌شود تا دو ساخت با ورودی یکسان، قابل مقایسه باشند.

## آزمون محلی

آزمون اختصاصی مولد را از ریشهٔ مخزن اجرا کنید:

```bash
.venv/bin/python -m unittest bitcoin4funsite/tests/test_github_pages_snapshot.py -v
```

آزمون‌ها تعداد و نشانی مرجع صفحه‌ها، حل شدن پیوندهای محلی، انتقال پیوندهای پویا به سایت اصلی، فهرست دقیق دارایی‌ها، نبود فایل‌های ممنوعه، بازسازی پاک و درستی فهرست منشأ را بررسی می‌کنند.

## مرز انتشار

اجرای مولد فقط فایل محلی می‌سازد. این کار هیچ تنظیم مخزن، تنظیم میزبانی، دامنه، شاخه، تعهد یا انتشار دوردستی را تغییر نمی‌دهد. انتشار باید در مرحله‌ای جدا و فقط با اجازهٔ صریح انجام شود.
