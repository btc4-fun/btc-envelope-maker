# btc4.fun

وب‌سایت آموزشی فارسی و ابزار آفلاین ساخت کارت بیت‌کوین؛ یک پروژهٔ تفریحی، نه وعدهٔ سود یا پیشنهاد سرمایه‌گذاری.

https://btc4.fun

## ساختار

ابزار تولید آفلاین و راهنمای چاپ:

btc_envelope_maker/

سایت، راهنماها، پیگیری سریال و استقرار:

bitcoin4funsite/

## مرز امنیتی

سایت فقط سریال و آدرس عمومی را از پایگاه داده می‌خواند. کلمات بازیابی، کلید خصوصی و فایل چاپی محرمانه نباید به سرور سایت، مخزن، ایمیل یا فرم اینترنتی منتقل شوند. برای استفاده از موجودی کارت، آن را با برنامهٔ معتبر به کیف‌پول تازهٔ خود منتقل کنید.

ابزار تولید و سایت دو فرایند مستقل‌اند؛ انتشار سایت به معنی رفع یافته‌های بازبینی امنیتی ابزار تولید نیست. پیش از استفاده با پول واقعی، محدودیت‌های ثبت‌شده را بخوانید:

SECURITY.md

## اجرای سایت

در مسیر سایت، محیط پایتون بسازید و وابستگی‌های قفل‌شده را نصب کنید:

```sh
cd bitcoin4funsite
python3 -m venv .venv
.venv/bin/pip install --require-hashes -r requirements.txt
.venv/bin/gunicorn --bind 127.0.0.1:8080 'app:create_app()'
```

صفحات آموزشی بدون پایگاه داده کار می‌کنند. پیگیری سریال به تنظیمات پایگاه داده و حساب فقط‌خواندنی نیاز دارد. هیچ درخواست خودکاری به سرویس بیرونی، شبکهٔ توزیع محتوا، کاوشگر زنجیره یا قلم اینترنتی انجام نمی‌شود. پیوند کاوشگر فقط با انتخاب خود کاربر باز می‌شود؛ سایت بدون اتصال به سرور خودش، اطلاعات زندهٔ سریال را ندارد و برنامهٔ تضمین‌شدهٔ بی‌اتصال نیست.

راهنمای استقرار، حساب‌ها و بازگشت:

bitcoin4funsite/DEPLOYMENT.md

## اجرای آزمون‌ها

```sh
python3 -m unittest discover -s bitcoin4funsite/tests -v
```

وابستگی‌های سایت باید در محیط اجرای آزمون نصب باشند. داده‌های آزمون فقط آدرس‌های عمومی شناخته‌شده‌اند و نباید شارژ شوند.

## استفاده از مولد

تنظیمات نمونه را به فایل محلی تبدیل کنید و راهنمای خود مولد را بخوانید:

```sh
cp btc_envelope_maker/config.example.toml btc_envelope_maker/config.toml
```

فایل تنظیمات واقعی، خروجی‌ها، دفتر آدرس‌های واقعی و پایگاه داده عمداً از مخزن کنار گذاشته شده‌اند. کلمات را فقط در محیط آفلاین مورداعتماد تولید کنید؛ فایل محرمانه را عمومی منتشر نکنید.

btc_envelope_maker/README.md
